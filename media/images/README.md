# Image Checklist

Recommended filenames:

- `hero-hover.jpg` — strongest completed-flight image
- `final-top.jpg`
- `final-side.jpg`
- `final-bottom.jpg`
- `cad-assembly.png`
- `cad-arm-detail.png`
- `electronics-stack.jpg`
- `receiver-wiring.jpg`
- `motor-test.jpg`
- `first-prototype.jpg`
- `failed-revision.jpg`

Use good lighting, a plain background, and landscape orientation when possible.
Do not upload 20 nearly identical images. Keep only images that explain the engineering story.
